# Aplicação de validação do LimpaAí

Ferramenta local criada para o GOAL 001.

## Executar

```powershell
cd D:\CLI\tiago\limpaai\validation-app
npm install
npm start
```

Abrir:

- http://localhost:4173
- http://localhost:4173/client.html
- http://localhost:4173/professional.html
- http://localhost:4173/dashboard.html

## Dados

As respostas ficam em:

- `data/clients.json`
- `data/professionals.json`

Esses arquivos são locais e não devem ser versionados.

## Exportação

O painel permite exportar as duas bases em CSV.

## Limitação

Esta aplicação é uma ferramenta de pesquisa local. Não é o MVP de produção.
