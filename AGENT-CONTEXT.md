# AGENT CONTEXT — LimpaAí

## Leitura obrigatória antes de qualquer alteração

1. `GOAL.md`
2. `docs/BLUEPRINT.md`
3. `docs/ESPECIFICACAO-FUNCIONAL-MVP.md`
4. `planning/DECISIONS.md`
5. `planning/BACKLOG.md`
6. relatório mais recente em `relatorios/`

## Ciclo obrigatório de trabalho

GOAL → auditar estado real → planejar a menor alteração possível → criar backup → implementar → testar localmente → publicar em homologação → testar publicamente → corrigir ou reverter → registrar relatório honesto.

## Regras

- Nunca declarar sucesso quando qualquer teste obrigatório falhar.
- Não ampliar escopo sem registrar decisão.
- Não misturar produção e homologação.
- Não armazenar documentos sensíveis em área pública.
- Não registrar CPF, documentos, chaves Pix ou conversas completas em logs.
- Não criar cobrança, retenção financeira ou seguro fictício.
- Toda regra financeira deve ser configurável e auditável.
- Toda alteração de status crítico deve gerar log.
- Após duas tentativas frustradas na mesma abordagem, mudar a estratégia e coletar evidências adicionais.
